# Roadmap

## Запланировано (из постановки)

- Полноценные фильтры и поиск: `GET /api/lenses`, фильтры по диапазонам (цена, вес, фокусное),
  нечёткий поиск по модели (`pg_trgm`, индексы уже есть), полнотекстовый поиск (`tsvector` + GIN).
- Страницы камеры и объектива (`/api/cameras/{brand}/{slug}`), параметры в роутере.
- Подбор «под случай»: ранжирование по `score` из `*_use_cases`, комбинации камера + объектив.
- Совместимость: объективы по `mount_id` камеры, предупреждение о кропе (`designed_for_format` vs `sensor_format`).
- Сравнение моделей.
- Админка: добавление/редактирование, очередь на проверку (`verified = false`), просмотр `source_url`.

## Идеи на будущее

- Переходники между байонетами (таблица `mount_adapters`: from → to, с автофокусом или без).
- Характеристики несъёмного объектива у компактов (фокусное, светосила).
- Справочник байонетов с поддержкой нескольких форматов (Sony E: FF + APS-C) для точного определения кропа.
- Текущие цены и история цен отдельно от `price_usd` (цена на старте).
- `verified_at` / `verified_by`, когда появятся пользователи админки.
- Отчёт импорта в JSON (`--json`) для автоматизации; журнал импортов в БД.
- Интеграционные тесты импорта и API на отдельной тестовой БД.
- Prod-конфигурация: nginx/Apache + php-fpm (`try_files $uri /index.php`), кэширование статики.
