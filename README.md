# camera-picker

Каталог фотокамер и объективов с фильтрами и подбором объективов под ситуацию.
(портрет, пейзаж, спорт, видео, макро и другое) и проверкой совместимости объективов по байонету.

**Стек:** HTML + CSS + JS без фреймворков · PHP 8.2+ (REST API, Composer) · PostgreSQL (PDO, pg_trgm)
